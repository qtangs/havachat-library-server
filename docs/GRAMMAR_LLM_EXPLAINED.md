# Grammar Enrichment with Pre-Generated LLM Explanations

## Overview

The `enrich_grammar` CLI now supports using pre-generated LLM explanations, allowing you to skip the LLM generation step and directly enrich grammar items with translations and romanization.

## Use Case

When you already have grammar explanations generated by an LLM (e.g., in a CSV file), you can use this feature to:
1. Skip the expensive LLM generation step
2. Focus on adding translations and romanization only
3. Process the entire dataset without the `--max-items` limitation

## CSV Format

The pre-generated LLM explanations file must be a CSV with the following columns:

- `front`: The target grammar item/pattern (e.g., "Modal verb 会 (learned ability)")
- `back`: The definition/explanation in English
- `examples`: Example sentences in Chinese, separated by `;;;` (e.g., "我会说中文。;;;她会做饭。;;;他不会开车。")

### Example CSV

```csv
front,back,examples
"Modal verb 会 (learned ability)","会 + Verb expresses learned skills or abilities acquired through study or practice. It answers the question 'do you know how to...?' and implies the ability was gained, not innate.","我会说中文。;;;她会做饭。;;;他不会开车。"
"Modal verb 能 (physical ability/permission)","能 + Verb expresses physical capability, possibility based on circumstances, or permission. It focuses on whether conditions allow the action, not whether you learned how to do it.","我今天能来。;;;他能吃很多。;;;你能看见吗?"
```

## Usage

### Basic Usage (with translation)

```bash
PYTHONPATH=src uv run python -m havachat.cli.enrich_grammar \
    --language zh \
    --level HSK1 \
    --enricher chinese \
    --output output/zh/hsk1/grammar.json \
    --llm-explained-file path/to/grammar_explained_by_llm.csv
```

This mode will:
- Parse the CSV file
- Add romanization (pinyin) for all Chinese text
- Translate examples to English using Azure Translation or LLM
- Generate enriched LearningItem objects

### Without Translation (fastest)

If you want to skip translation entirely:

```bash
PYTHONPATH=src uv run python -m havachat.cli.enrich_grammar \
    --language zh \
    --level HSK1 \
    --enricher chinese \
    --output output/zh/hsk1/grammar.json \
    --llm-explained-file path/to/grammar_explained_by_llm.csv \
    --skip-translation
```

This mode:
- No LLM client needed
- No translation services required
- Examples will have `[Translation unavailable]` as translation
- Romanization (pinyin) is still added

### With Parallel Processing

For large datasets, use parallel processing:

```bash
PYTHONPATH=src uv run python -m havachat.cli.enrich_grammar \
    --language zh \
    --level HSK1 \
    --enricher chinese \
    --output output/zh/hsk1/grammar.json \
    --llm-explained-file path/to/grammar_explained_by_llm.csv \
    --parallel 5
```

## Behavior Changes

When using `--llm-explained-file`:

1. **`--input` is NOT required**: The normal source CSV file is not needed
2. **`--max-items` is IGNORED**: All items in the file are processed
3. **LLM is only used for translation**: If you use `--skip-translation`, no LLM is needed at all
4. **Checkpoints still work**: Use `--resume` to continue from a previous run

## Output Format

The enriched output follows the standard LearningItem schema:

```json

  "language": "zh",

  "target_item": "Modal verb 会 (learned ability)",
  "definition": "会 + Verb expresses learned skills...",

    }
  ],

```

## Example Workflow

1. **Generate explanations with LLM** (outside this tool):
   ```python
   # Use your preferred LLM to generate grammar explanations
   # Save as CSV with front,back,examples columns
   ```

2. **Enrich with translations**:
   ```bash
   PYTHONPATH=src uv run python -m havachat.cli.enrich_grammar \
       --language zh --level HSK1 \
       --enricher chinese \
       --output output/zh/hsk1/grammar.json \
       --llm-explained-file grammar_explained_by_llm.csv
   ```

3. **Result**: Fully enriched grammar items ready for the app

## Benefits

- **Cost Savings**: Skip expensive LLM calls for definition generation
- **Flexibility**: Use any LLM or manual curation for explanations
- **Speed**: Process entire datasets without limits
- **Quality Control**: Review and refine explanations before enrichment
