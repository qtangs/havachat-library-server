# Vocabulary Enrichment with Pre-Generated LLM Explanations

## Overview

The `enrich_vocab` CLI now supports using pre-generated LLM explanations, allowing you to skip the LLM generation step and directly enrich vocabulary items with romanization, traditional Chinese, and translations.

## Use Case

When you already have vocabulary explanations generated by an LLM (e.g., in a CSV file), you can use this feature to:
1. Skip the expensive LLM generation step
2. Focus on adding romanization, traditional Chinese, and translations only
3. Process the entire dataset without the `--max-items` limitation

## CSV Format

The pre-generated LLM explanations file must be a CSV with the following columns:

- `front`: The target word and part of speech, separated by `;;;` (e.g., "银行;;;noun")
- `back`: The definition/explanation in English
- `examples`: Example sentences in Chinese, separated by `;;;` (e.g., "我去银行。;;;她在银行工作。;;;银行在哪里?")

### Example CSV

```csv
front,back,examples
"银行;;;noun","A financial institution where people can save money or get loans.","我去银行。;;;她在银行工作。;;;银行在哪里?"
"医生;;;noun","A person who is trained to treat people who are ill or injured.","他是医生。;;;我去看医生。;;;医生说我很健康。"
```

## Usage

### Basic Usage (with translation)

```bash
PYTHONPATH=src uv run python -m havachat.cli.enrich_vocab \
    --language zh \
    --level HSK1 \
    --enricher chinese \
    --output output/zh/hsk1/vocab.json \
    --llm-explained-file path/to/vocab_explained_by_llm.csv
```

This mode will:
- Parse the CSV file
- Add romanization (pinyin with tone marks)
- Add traditional Chinese characters
- Add numeric pinyin (e.g., yin2 hang2)
- Translate examples to English using Azure Translation or LLM
- Generate enriched LearningItem objects

### Without Translation (fastest)

If you want to skip translation entirely:

```bash
PYTHONPATH=src uv run python -m havachat.cli.enrich_vocab \
    --language zh \
    --level HSK1 \
    --enricher chinese \
    --output output/zh/hsk1/vocab.json \
    --llm-explained-file path/to/vocab_explained_by_llm.csv \
    --skip-translation
```

This mode:
- No LLM client needed
- No translation services required
- Examples will have empty `translation` fields
- Romanization and traditional Chinese are still added

### With Parallel Processing

For large datasets, use parallel processing:

```bash
PYTHONPATH=src uv run python -m havachat.cli.enrich_vocab \
    --language zh \
    --level HSK1 \
    --enricher chinese \
    --output output/zh/hsk1/vocab.json \
    --llm-explained-file path/to/vocab_explained_by_llm.csv \
    --parallel 5
```

## Behavior Changes

When using `--llm-explained-file`:

1. **`--input` is NOT required**: The normal source TSV file is not needed
2. **`--max-items` is IGNORED**: All items in the file are processed
3. **LLM is only used for translation**: If you use `--skip-translation`, no LLM is needed at all
4. **Checkpoints still work**: Use `--resume` to continue from a previous run

## Output Format

The enriched output follows the standard LearningItem schema:

```json
{
  "id": "uuid",
  "language": "zh",
  "category": "vocab",
  "target_item": "银行",
  "definition": "A financial institution where people can save money or get loans.",
  "examples": [
    {
      "text": "我去银行。",
      "translation": "I'm going to the bank.",
      "media_urls": []
    }
  ],
  "romanization": "yínháng",
  "sense_gloss": null,
  "pos": "noun",
  "aliases": ["銀行", "yin2 hang2"],
  "level_system": "hsk",
  "level_min": "HSK1",
  "level_max": "HSK1",
  "created_at": "2026-02-02T08:56:06Z",
  "version": "1.0.0"
}
```

### Key Features in Output

- **romanization**: Pinyin with tone marks (yínháng)
- **aliases**: Contains traditional Chinese (銀行) and numeric pinyin (yin2 hang2)
- **examples**: With Chinese text and English translations
- **pos**: Part of speech from the CSV

## Example Workflow

1. **Generate explanations with LLM** (outside this tool):
   ```python
   # Use your preferred LLM to generate vocabulary explanations
   # Save as CSV with front,back,examples columns
   # front format: word;;;pos
   ```

2. **Enrich with translations**:
   ```bash
   PYTHONPATH=src uv run python -m havachat.cli.enrich_vocab \
       --language zh --level HSK1 \
       --enricher chinese \
       --output output/zh/hsk1/vocab.json \
       --llm-explained-file vocab_explained_by_llm.csv
   ```

3. **Result**: Fully enriched vocabulary items ready for the app

## Benefits

- **Cost Savings**: Skip expensive LLM calls for definition generation
- **Flexibility**: Use any LLM or manual curation for explanations
- **Speed**: Process entire datasets without limits
- **Quality Control**: Review and refine explanations before enrichment
- **Automatic Processing**: Pinyin, traditional Chinese, and numeric pinyin are generated automatically
